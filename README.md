# PassGuard – Password Manager

**PassGuard** is a Python-based password manager developed using Tkinter. It provides a simple graphical interface for generating, managing and evaluating passwords while introducing important concepts in software development and cybersecurity.

##  Project Overview

PassGuard was developed as a practical learning project to explore how Python can be used to build interactive desktop applications.

The project focuses on password generation, password strength evaluation, user interaction and basic password security concepts.

##  Features

- **Password Generation:** Generate passwords using a combination of letters, numbers and special characters.
- **Password Strength Checker:** Evaluate password strength based on selected criteria.
- **Password Hashing:** Demonstrate password hashing using SHA-256.
- **Copy to Clipboard:** Copy generated passwords conveniently.
- **Graphical User Interface:** Interact with the application through a Tkinter interface.
- **Clear History:** Remove previously generated password records.
- **User Interaction:** Respond to user actions through event-driven programming.

##  Technologies Used

- Python
- Tkinter
- Hashlib

##  Getting Started

### Requirements
- Python 3.x
- Tkinter (usually included with standard Python installations)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/PassGuard.git
   ```

2. Navigate to the project folder:

   ```bash
   cd PassGuard
   ```

3. Run the application:

   ```bash
   python PassGuard.py
   ```
